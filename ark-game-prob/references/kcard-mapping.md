# 機制 → 手法卡（K 卡）對照 與 隱性規則「設計目的」寫法

> 給填 prob-spec.md 人工區 `competitor`（§5）與 `hidden-rules`（§6）的人／agent（prob-architect）。
> 腳本不會替你填：K 卡取捨是判斷，不是搬運。K 卡原文在 team 知識庫 `knowledge/shared/raw/prob-methods/`。

## §5 手法對應：怎麼填

每一列 = 一個**可調的機制**（通常對應一張參數表），不是一個符號或一個數字。

| 欄 | 寫什麼 | 不要寫 |
|---|---|---|
| 機制（參數表） | 表編號 + 一句話（如 `表 M-1 輪帶組權重混合`）| 只寫表編號 |
| 說明 | 這個機制在**這款**怎麼被用（旋鈕是什麼、調它會動到哪個數字）| K 卡的通用定義 |
| 對應手法卡 | `K-022`；近似就寫「近似 K-023」；沒有就寫 `PROPOSED 新設計` + 一句為何現有卡不涵蓋 | 硬套一張 |
| 收錄目的（選用） | 這款值得反推回知識庫的點（新卡候選 / 既有卡的實證案例）| 空白請留空，不要填「—」|

常見對應（slot）：

| 機制 | 常見 K 卡 | 判斷點 |
|---|---|---|
| 多組輪帶 × 權重抽選（表M-1 類）| K-022 轉輪組權重混合 | 權重是 RTP 旋鈕、單條帶不動 → 是；只有一組帶 → 否 |
| FG 強中弱 / 超強分層（表F-1 類）| K-024 FG 強度分層 | 有極端稀有組（≤ 1%）且貢獻不成比例 → 典型 |
| 收集型 FG 的次數 × 分數雙權重（表F-2 類）| K-007 面額曲線、KX-008 收集型雙權重 | 次數與分數各自抽 → KX-008；只有分數 → K-007 |
| 復活 / 續命（表F-4 類）| K-021 FG 復活架構 | 純表演層不改 RTP → K-021；會加獎 → 另找或 PROPOSED |
| Scatter 自帶分數 / 顏色分級（表M-2 / M-5 類）| K-023 SC 分數當體驗旋鈕 | 進場與假轉兩套權重 → 典型 |
| 保底 / 必中 feature | K-020 FG 保底 | — |

## §6 隱性規則：規則 + 設計目的，缺一不可

製作方針第 4 點：「加入機率隱性規則（更改需與編導規格書同步）…隱性規則須加上設計目的」。

| 欄 | 寫法 |
|---|---|
| 規則 | 玩家看不到、但決定數字怎麼跑的約束。用「若…則…」或「X 固定為 Y」陳述；指出它在哪張表 / 哪個 config 鍵 |
| 設計目的 | 為什麼要這樣：體感（張力 / 節奏 / 辨識度）、風險（封頂 / 保底）、工程（索引語意 / 編碼慣例）。一句話，講清楚**不這樣會怎樣** |
| 對應表 / K 卡 | `表 F-4 / K-021`；config 鍵名也可（`MaxWin`）|
| 更改需同步 | 編導規格書 / 設定檔 / 引擎 / 美術 — 誰會被這條規則牽動 |

寫法檢查：規則若含數字，請在同格標來源（人工區不受 PS-NUM 保護）；設計目的不要寫成規則的重述。

## 彌勒佛（milefo）範例（2026-10-06）

| 規則 | 設計目的 | 對應 | 更改需同步 |
|---|---|---|---|
| 復活為演出層攔截：FG 結束前若總分達門檻倍數，依 50:50 決定是否保留部分金龍／彩龍續玩演出 | 製造「起死回生」張力；不額外給獎、不改 RTP 統計，所以可大膽調體感 | 表 F-4 / K-021 | 編導規格書 |
| 金幣在超強組出現次數為 0，名額讓給高倍金龍／彩龍；鯉魚在超強組固定 888 | 「越強的場越少小獎、越多大獎」，拉開層次 | 表 F-2 / K-024 | 編導規格書 |
| 假轉時 SC/SS 仍自帶分數；SS 負值（−2/−3/−4）= 乘倍不是扣分 | 每手都有小回饋；負值編碼是引擎慣例，規格書須註明避免誤讀 | 表 M-2 / K-023、FakeSSScores | 設定檔 |
| 輪帶組換帶：旗標 1 的輪改用 Reels_1（R1–R4 無 SC、R5 無 SS）| 用「換帶」而非「改帶」調 SC 密度，單條帶內容不變只動權重，RTP 可追溯 | 表 M-1 / K-022 | 設定檔 |
| 單場贏分受 MaxWin 10,000 倍封頂（FG 原生最大 31,120 倍）| 封極端尾端風險；代價是總 RTP 比理論低約 0.09 pp | MaxWin | 編導規格書 |

對應 K 卡總表（彌勒佛）：M-1 → K-022；F-1 → K-024；F-2 → K-007 · KX-008；F-4 → K-021；M-2 / M-5 → K-023。
