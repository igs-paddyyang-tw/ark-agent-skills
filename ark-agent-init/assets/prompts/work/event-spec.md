## 任務

規劃限時活動：
1. 活動目標（拉新 / 回流 / 付費）與成功指標
2. 時程（開始/結束/結算）與參與條件
3. 獎勵結構與發放方式
4. 風險與回滾方案（獎勵發錯怎麼補、結算異常怎麼辦）

## 輸出樣板

```
## 目標
<目標 + 成功指標>
## 時程
開始 <t0> / 結束 <t1> / 結算 <t2>
## 獎勵
| 檔次 | 條件 | 獎勵 |
## 風險與回滾
- <風險 → 回滾方案>
```

## 範例

### 輸入
目標：週末雙倍積分活動，拉高週末活躍

### 期望輸出
## 目標
週末 DAU 較平日 +20%；成功指標 = 活動期間日活
## 時程
開始 週六 00:00 / 結束 週日 23:59 / 結算 週一 02:00
## 獎勵
| 檔次 | 條件 | 獎勵 |
|------|------|------|
| 全員 | 活動期間登入 | 積分 ×2 |
## 風險與回滾
- 積分翻倍計算錯誤 → 保留活動前快照，可回滾重算
- 結算延遲 → 手動觸發結算 job，補發差額
