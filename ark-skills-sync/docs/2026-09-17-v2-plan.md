# ark-skills-align v2 執行計畫

分階段推進,每階段一 commit,deterministic gate。向後相容硬要求:每階段 audit 既有行為不回歸。
套件段(defaults.skills/scheduler/api-health)在 paddy 開發源,列為交接不在本 repo 執行。

## W0 — 版本基底 + 腳本歸位（AC-01/02/04/21/22/23）

- metadata-schema.md 升 v1.2(version 必填 semver、depends_on 物件、contract_files)
- `backfill_metadata.py --versions`:52 個 version(x.y→x.y.0、缺者 1.0.0)、depends_on 字串→物件
- `gen_manifest.py`:產 release/manifest.json + index.json
- `requirements.txt`(pyyaml)
- 腳本歸位:check_consumers/gen_readme 搬入 skill scripts/(根留 thin wrapper)、hooks/pre-push 搬入(根留 symlink)
- onboarding-gate.md 去 legacy 類別 + taxonomy 名冊門檻

**Gate**:audit P0/P1=0 且 version 52/52 semver;manifest skill 數=active 數(52);根 wrapper+搬入腳本 --help exit 0。

## W1 — audit AL 規則 + 穩定 ID（AC-05/06/07/08）

- 既有 14 條賦 AL-001~014(語意不變,向後相容)
- AL-101~106(version 缺/非 semver 過渡 P2、contract 變未 bump、major 無 Breaking、depends_on 無範圍、上游範圍不可滿足 P0、updated 早於 contract 變更)
- --json 穩定 ID、exit 0/1/2
- fixtures(每條 AL 一 pass 一 fail);AL-105 接 gen_manifest 前置

**Gate**:fixtures 全過;反證 — 造 A 需 B≥2/B 為 1.x → gen_manifest exit 2;audit 既有行為不回歸。

## W2 — 消費端契約 + align_sync（AC-09~16）

- consumer-contract.md:skills-matrix.yaml/skills.lock.json schema
- `align_sync.py`:plan(--waves 不改檔)/apply(--wave N --yes exit 10)/verify/migrate(AST 抽 sync_skills)/resolve
- AL-201~204(pin 不可滿足/複本落後警告/local-drift/懸空)、AL-301~305(base tier same-version/depends_on 範圍/SOUL≠matrix/distill)
- tree_hash + semver 內建實作

**Gate**:假 team fixture — migrate 產 matrix+lock;plan --waves 三波;apply --wave 1 --yes 後 verify P0=0;手改複本檔→AL-203。

## W3 — 版本感知 + 廣播（AC-17~20；套件段交接）

- `align_sync.py verify --remote`(取 manifest,lag/breaking/unknown,斷網退回本機標 unreachable)+heartbeat
- pre-push v2:major/contract_hash/depends_on 變更→Alignment Notice
- `notice_build.py`:--impact JSON→md-report review 型
- 🔴 套件 defaults.skills/scheduler/api-health = **交接 paddy 開發源**(本 repo 只做 skill 端腳本)

**Gate**:假 manifest — lag/breaking/unknown 三態各 fixture;斷網→unreachable;同版連兩天只發一次;pre-push major bump→notice report_lint exit 0。

## W4 — 收斂（AC-24）

- SKILL.md 兩模式(upstream/consumer)重寫瘦身 ≤120 行,敘事移 ops-playbook.md
- evals(upstream 3+consumer 3+negative 2)
- 🔴 其他 skill 文件改(role-profile schema 1.1、agent-init role-skills-map.yaml、team-design/team-builder)= 交接

**Gate**:prompt_lint --type skill 無 P0/P1;audit P0/P1=0;gen_readme --check 綠。
