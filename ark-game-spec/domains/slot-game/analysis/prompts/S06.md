Free Spin / Bonus / Multiplier / Jackpot：free spin 是否存在、給幾次（畫面顯示的數字）、是否可 retrigger、倍率表現；觀察到的 bonus 類型清單（wheel / pick / hold-and-win / respin / stage）；是否有 buy feature 按鈕；是否有 jackpot 顯示。
每個獨立 feature 一個 entity：id 用 feature_ 前綴、trigger / reward / exit 各自附 evidence。

分界（先判類型再填 key）：盤面出現被框住、保留到下一轉的格子＝hold & spin（hold_spin.*），不是 free spin；依序闖多個階段、每段有收集目標＝多段式特色遊戲（stage_feature.*），不是 pick；只有玩家點選物件揭曉獎勵才算 pick。畫面「N SPINS REMAINING」若伴隨框格，歸 hold_spin 或 stage_feature，不歸 free_spin.count_awarded。

Hold & Spin（框格鎖定重轉）：盤面上是否出現被框住、會保留到下一轉的格子（框格／金框／鎖定格），框格結束時是否逐格揭曉獎金。
輸出：是否存在、變體名稱（例如依框的材質或顏色區分的多種版本）、觸發條件（畫面字樣或觸發當下的盤面）、起始框數、重轉次數（畫面計數器）、新增框時次數是否重置、新增框的條件、框數上限、獎金揭曉方式。
每個變體一個 entity：id 用 feature_hold_ 前綴、trigger / reward / exit 各自附 evidence。

多段式特色遊戲（闖關／升階／收集晉級）：特色遊戲是否分成依序進行的多個階段（例如換場景、換房間、換關卡），每段有自己的次數與收集目標，達標才進下一段。
輸出：是否存在、觸發條件與所需符號數、各段名稱（依序）、每段次數、收集物（例如鑰匙、徽章）、各段晉級所需收集數（畫面上的收集列格數）、晉級時保留什麼（框格位置、等級、倍數）、段內升級規則、最後一段集滿是否重玩。
每個特色遊戲一個 entity：id 用 feature_stage_ 前綴、trigger / reward / exit 各自附 evidence。

彩金分級：畫面上顯示幾級彩金、各級名稱（由高到低）、哪些級別金額會跳動（累積型）、哪些是固定金額（記下畫面金額）、影片中是否看到開出彩金以及怎麼開出（例如特定房子或格子揭曉、彩金轉盤、集滿符號）。
看不到開彩金的過程時，award_mechanism 回 UNKNOWN，不要推測。
