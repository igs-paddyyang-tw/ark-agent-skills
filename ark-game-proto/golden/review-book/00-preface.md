# 序：這本拍板書要你決定什麼

## 為什麼有這本書

Huff N' Puff Open House 從競品影片走到可以玩的試玩版，九個階段已經完成八個：競品分析、遊戲規格書、機率規格書、2,000 萬局 Go 快測、機率報告、可視化驗證台、試玩版、Game Server 雛型。第九個階段「上線成效」要等遊戲真的上線才會有。

研發能做的驗證都做了：快測三向判定 confirmed、驗證台精算對得上快測、兩套引擎逐局比對 40 萬局零誤差、真瀏覽器跑過每一種特色遊戲。剩下的不是技術問題，是只有人能下的判斷——好不好玩、要不要定版、要不要加功能、美術怎麼換。

這個資料夾連同成品、驗收截圖與這本書，我們叫做 **拍板包**；整包可以直接傳給人，離線打開就能看、能玩。

## 這本書給誰

給要決定這款遊戲能不能進正式開發的製作人、主管與機率負責人。不需要會寫程式，但第一章會請你親手玩幾局——體感沒辦法用表格代替。

## 讀完你會

- 用 `play.html` 的強制情境親手確認五種特色遊戲的體感是否到位
- 判斷正式機率 **kb-v1** 是否可以從 candidate 升為定版
- 決定 Free Games（6 頂安全帽）是否進 v1
- 排定把競品素材換成正式美術的範圍與時程

## 全書路線圖

| 章 | 要拍板的事 | 建議 |
|---|---|---|
| 第 1 章 R-1 | 五種特色遊戲「多久來一次、來了多爽」是否符合設計意圖 | 先玩再決定；不到位就回機率規格書調頻率或均倍 |
| 第 2 章 R-2 | 正式機率 kb-v1 是否定版 | R-1 通過即升 approved |
| 第 3 章 R-3 | Free Games 是否進 v1 | v1 不做 |
| 第 4 章 R-4 | 競品素材換正式美術 | 排美術時程；換圖只改設定檔 |
| 附錄 | 成品清單、驗收紀錄、九階段狀態、報告 | 每次發布自動更新 |

建議順序就是章節順序：體感先過，機率才值得定版；機率定了，才談加不加功能與美術。
