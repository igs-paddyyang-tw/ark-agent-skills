# ark-db-query v3.0 規格書

## 目標

把 v2.0 的守門從「提詞層 + 正則」下沉到「引擎層 + 契約層」的 deterministic 機制。
向後相容為**硬要求**：v2.0 所有指令列與 stdout 欄位保留，只新增欄位與 exit code。

## 驗收條件（AC，對齊 design §2.2 findings）

### 守門下沉（P0）

- **AC-01**（F-01）：前置註解無法繞過 read-only 守門。`-- note\nDELETE FROM t` 必須 `GATE_BLOCKED`。
- **AC-02**（F-02）：巢狀/腳本寫入入口被攔。`BEGIN…END`、`EXECUTE IMMEDIATE 'DELETE'`、`CALL`、MSSQL `EXEC`/`SELECT…INTO`、PG `COPY…TO PROGRAM`、MySQL `LOAD DATA` 全部 `GATE_BLOCKED`。
- **AC-03**（ADR-001）：L1 改 allowlist——語句首 keyword ∉ {SELECT,WITH,SHOW,DESCRIBE,EXPLAIN,PRAGMA} 一律拒絕（封閉集合）。
- **AC-04**（F-05/F-06）：BQ 不再改寫 SQL 補 LIMIT；`--limit` 由 `max_results` 實作，dry-run 與執行同一份 SQL。`…LIMIT 10 OFFSET 5` 不再誤補。
- **AC-05**（ADR-001 L3）：BQ 用 dry-run 的 `statement_type != SELECT` 時 `GATE_BLOCKED`（伺服端判定）。

### 資源保護（P0）

- **AC-06**（F-03）：pg/mysql/sqlite 用串流 cursor，`SELECT *` 大表逐筆讀到 limit 就停，峰值 RSS 不隨表大小線性成長（10 萬筆 sqlite `SELECT *` < 100 MB）。
- **AC-07**（F-04）：`--query-timeout` 以引擎機制實作查詢逾時，逾時回 `TIMEOUT`（exit 7）。
- **AC-08**（F-07）：BQ job 逾時後必呼叫 `job.cancel()`。
- **AC-09**（F-08）：BQ 支援 `--params`（named `@x` → ScalarQueryParameter）。
- **AC-10**（F-09）：新增 `db_export.py`,契約與 bq_export 對齊(串流寫檔、stdout 回 count+樣本)。

### 多 agent 治理（P1）

- **AC-11**（F-10）：檔案鎖 ledger,dry-run 後「當日累計+估算 > 預算」→ `BUDGET_EXCEEDED`(exit 4),執行前擋。
- **AC-12**（F-11）：每次執行(成功/失敗)追加一行 ledger jsonl(ts/agent_id/sql_sha256/statement_type/bytes/cost/exit_code)。
- **AC-13**（ADR-004）：ledger 目錄不可寫 → fail-closed(exit 2);`ARK_DB_LEDGER_DISABLED=1` 可明示關閉。
- **AC-14**：9 並發進程各 append 100 行 → ledger 行數 = 900 無損毀。

### 契約 v1.1（P1）

- **AC-15**（ADR-005）：契約加 `contract:"1.1"`、`meta.skill_version`、`meta.agent_id`、`meta.sql_sha256`、`meta.gate`、`data.truncated_by`。
- **AC-16**（F-12）：exit code 分流(2 BAD_INPUT/3 GATE_BLOCKED/4 BUDGET_EXCEEDED/5 CONN_FAILED/6 QUERY_FAILED/7 TIMEOUT/8 DRIVER_MISSING)。
- **AC-17**（F-12）：stdout 純度機制化——driver 呼叫包 redirect_stdout(stderr),stdout 保證單一 JSON。
- **AC-18**（F-13）：`--max-stdout-bytes`(預設 64 KiB),bytes 截斷,`truncated_by="bytes"`。

### 品質/治理（P2）

- **AC-19**（F-14）：`bq_schema tables --brief` 跳過 get_table(免 N+1)。
- **AC-20**（F-15/F-16）：db_health 改用 drivers.py 工廠,BQ 憑證檢查與 bq_client 同一份邏輯。
- **AC-21**（F-17）：mongo projection 排除 `_id` 時不產 `"_id":"None"`。
- **AC-22**（F-18）：`--password` deprecated(stderr 警告)。
- **AC-23**（F-19/ADR-006）：`__version__.py` 單一版號,`meta.skill_version` 自報。
- **AC-24**（F-20）：W0 反證測試在 v2.0 上必須紅(≥8),證明抓得到現有漏洞。

## 向後相容（硬要求）

- **AC-BC-1**：v2.0 所有指令列參數保留(`--timeout` 保留為 `--query-timeout` 別名)。
- **AC-BC-2**：stdout 成功契約舊欄位(`success/data.rows/count/truncated/out_file/meta`)不刪不改語意。
- **AC-BC-3**：`--out` jsonl/csv 格式不變(下游 etl-pipeline/chart-generator 消費)。
- **AC-BC-4**：既有 `test_sqlite_contract.py` 全綠(不修測試遷就實作)。
