# 共用情報知識庫概覽

本櫃（`knowledge/shared/`）存放 market-team 的**共用情報**：
- 排程自動蒸餾的市場掃描結果
- 使用者放入的參考素材
- 跨 agent 共用的競品/趨勢知識

> 本團隊各 agent 自己分析產出的情報放 `knowledge/market-team/`。
> 知識庫都經蒸餾：raw（給人查證）→ ingest → wiki（給 AI 檢索）。
