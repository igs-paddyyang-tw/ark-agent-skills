📖 AI Bot — API

💬 Chat ⚙️ Dashboard 📖 Wiki 🕸️ Graph 🏗️ Builder 📡 API

專家 Agent 的 RESTful API。所有端點都在 http://localhost:8000 下。

🔗 Swagger UI（互動式測試） 🔗 ReDoc（完整文件）

🏥 Core 基礎

GET /health
健康檢查
GET /api/v1/health
健康檢查（含服務名稱）

🛠️ Skills 技能

GET /api/v1/skills
列出所有已註冊的 Skills

📚 Wiki 知識庫

POST /api/v1/chat
統一對話 API（走完整路由：CLI → Wiki → Gemini）— Body: {"message": "...", "agent_id": "admin"}
POST /api/v1/wiki/query
查詢知識庫（RAG）— Body: {"q": "搜尋關鍵字"}
POST /api/v1/wiki/ingest
匯入 knowledge/raw/ → wiki/（執行 ingest）
GET /api/v1/wiki/lint
檢查 Wiki 健康度（frontmatter 完整性）
GET /api/v1/wiki/pages
列出所有 wiki 頁面（filename + title）
GET /api/v1/wiki/pages/{filename}
取得指定頁面的完整 Markdown 內容
