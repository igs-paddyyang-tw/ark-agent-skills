# 自我探索準則（E1–E16）

> 清單是「一定要測的」；這份是「AI 自己去找問題」的方法。每條準則 = 一類常見問題 + 怎麼用一兩個動作證實。
> 例子都來自 2026-10-07/08 金猴爺兩輪試玩（手機正式帳號 + BlueStacks 新帳號），那兩輪 17 個問題裡有 14 個是清單外自己找到的。
> 用法：`explore --heuristic E1 --hypothesis "…" --method "…"`，做完回填 `--status issue|ok|inconclusive --result …`。

| 代號 | 準則 | 怎麼找 | 怎麼證實 | 實例 |
|---|---|---|---|---|
| E1 | 規則頁 vs 實際 | 每個玩過的遊戲都開「i / 遊戲資訊」讀完，把可驗的數字列成假設（觸發條件、次數、倍數、賠率單位） | 觸發時數倒數 / 讀結算，與規則逐條對 | 福爾摩斯規則 5 次免費旋轉、實際 8 次；賠率 1 單位 = 押注 ÷ 40 驗證相符 |
| E2 | 對帳 | 每 5–10 把、每次特色遊戲 / 寶箱 / 任務獎勵結算 | `ledger`：after − before = win − bet×spins；對不上先排除延後退款、加成、讀錯 | 13 次結算全相符；多米諾 1 筆先不符，後來發現是中斷牌局延後退款 |
| E3 | 每顆按鈕都要有回應 | 大廳、機台、功能頁的每個入口點一次 | 沒反應 → `mark --outcome noresp`；鎖住 / 貨幣不足有沒有說明條件 | 轉卡機 0 福幣按抽獎沒反應；交誼廳「紀錄」3 種點法都沒反應；鎖住功能不說幾級解鎖 |
| E4 | 彈窗分類與密度 | 每個彈窗都 `popup` 分類（免費 / 付費 / 資訊 / 對外） | 數同一次登入、回大廳一次跳幾個付費窗 | 重開 App 連跳 3 個付費窗；回大廳幾乎每次都跳禮包 |
| E5 | 跨畫面數字一致 | 同一件事在兩個畫面出現的數字（期限、獎勵、公式、進度） | 截兩張並排對照 | 新手任務「保留 72 小時」vs 地圖「還剩 6 天」；骰子小字 ×1,200 但 15 點給 160,000 |
| E6 | 預設值與勾選 | 進場押注、說明窗只有一顆按鈕、預設勾選框 | 按之前讀一次、按之後讀一次 | 額外押注說明只有「確定」，按下去押注變 1.5 倍（三台都這樣）；進機台預設押注 200 萬–330 萬 |
| E7 | 返回鍵 / 離開 | 每個場景按一次系統返回鍵、找離開路徑 | 有沒有「要離開嗎？」確認；返回會不會直接結算 / 領取 | 老虎機按返回直接回大廳；魚機返回無效、選單自動收起後點下去變開砲；簽到 X 沒反應、返回反而領取 |
| E8 | 穩定性 / 閃退 | 進出重載場景（魚機、大型機台）、長時間掛機、斷線後再進 | `logcat` 存證；同路徑 ≥ 3 次 + 換條件重現，記 `--repro` | 進魚機 SIGABRT（Il2Cpp 例外沒接住），重現 0/11，差在「剛斷線重連」與「連續跑 6 小時」 |
| E9 | 網路與錯誤碼 | 記下每個錯誤碼與當時實際網路狀況 | 重連後回到哪裡？訊息跟實況一致嗎？ | 4150002 時網路其實正常；重連後跳 8020「其他裝置在玩」但沒有其他裝置 |
| E10 | 新手引導鎖定 | 教學期間試按規則、選單、其他功能 | 哪些被鎖、鎖了有沒有提示 | 教學期間「i」與選單按不了；角色「邀請」要先做完角色廳教學，畫面沒提示 |
| E11 | 外部跳轉 | 「免費領」「社群」「客服」類按鈕 | 有沒有先提示就跳出 App（只按返回，不在外部做任何事） | 福星卡「免費領」直接開 Chrome 的 Discord 登入頁 |
| E12 | 命名 / 語系 / 圖示一致 | 同一功能兩個入口、兩種語言、兩個很像的圖示 | 截圖並排 | 七日回饋 = 每日簽到（兩個名字）；角色廳教學圖是日文介面；貓爪 vs 貓糧圖示很像 |
| E13 | 自動續行陷阱 | 掃蕩券、自動旋轉、自動配桌、倒數自動使用 | 特色遊戲結束 / 結算後會不會自己繼續花錢；停止鈕在動畫中能不能按 | 掃蕩券結算後「等待 2 秒自動使用」，兩次都沒攔住，多花約 330 萬；多米諾結算後自動配下一局 |
| E14 | 門檻與表演 | BIG WIN / MEGA WIN 的觸發門檻、結算動畫 | 記贏分 / 押注倍數 | 贏 2,250（押注 1.5 倍）也跳 BIG WIN；COMBO BIG WIN 被誤認為進免費遊戲 |
| E15 | 貨幣不足與解鎖提示 | 免費局用完、0 代幣、VIP 限定 | 卡住時畫面有沒有告訴玩家怎麼取得 | 花火くじ免費局後代幣 0 只顯示「代幣不足」；撲克大亨點了直接跳付費窗不說 VIP 幾級 |
| E16 | 清單探索重點 | 清單「探索重點」每一條 | 轉成具體假設再做 | — |

## 排序原則

1. **會讓玩家不知情花錢的**（E6、E13、E2）與**閃退**（E8）先做——這兩類最可能是「高」。
2. **規則 / 數字一致**（E1、E5）次之——AI 讀規則頁再對照實際，是人工最容易漏、AI 最擅長的。
3. **介面與文案**（E3、E7、E10、E11、E12、E14、E15）最後，但這類數量最多，邊玩邊記。

## 好假設 vs 壞假設

| 壞 | 好 |
|---|---|
| 看看押注設定 | 說明窗的「確定」會改到押注（按前讀 880，按後應仍是 880） |
| 測試穩定性 | 進暗雷龍殿 10 次不會閃退；若閃退，與「剛斷線」有關 |
| 檢查規則 | 福爾摩斯 3 個 SCATTER 送 5 次免費旋轉（規則頁第 2 頁） |
| 彈窗很多 | 同一次登入跳超過 2 個付費窗 |

## 不要做的探索

- 任何需要付費、評分、綁定、接觸真人的路徑（安全邊界見 `playtest-sop.md`）。
- 斷主機網路；刪裝置檔案；改裝置設定（語系、時間）除非清單明寫。
- 為了湊探索數量做沒有假設的亂點——探索的價值在「先猜、再證實」。
