# 金猴爺 新手體驗測試

## 基本測試

### 登入與大廳
- [ ] 開 App 讀取到 100% 進大廳，無閃退 ｜ 預期：看到大廳、餘額、機台卡片
- [ ] 登入彈窗串全部關得掉（免費領取、付費按 X） ｜ 預期：每個彈窗都有可用的關閉方式，不卡住
- [ ] 每日簽到 / 每日登入獎勵領取 ｜ 預期：領取後餘額增加金額 = 獎勵金額
- [ ] 大廳下方每顆按鈕都點一次（消息、背包、福星卡、公會、限定優惠…） ｜ 預期：每顆都有回應；鎖住的有提示條件

### 新手流程
- [ ] 新帳號新手教學完整走完 ｜ 預期：教學能完成，期間不卡關
- [ ] 冒險地圖 5 關任務全部完成 ｜ 預期：每關寶箱金額 = 餘額增加；最終寶箱倒數與說明一致

### 機台與對帳

#### B-010 每台玩過的機台都讀規則頁並對照實際
步驟：
- 進機台 → 開「i」或「… → 遊戲資訊」讀完規則
- 押注降到最低，旋轉到觸發特色遊戲或 300 把為止
- 觸發時記錄實際次數 / 倍數 / 結算
預期：規則頁寫的觸發條件、次數、賠率與實際一致；結算金額 = 餘額增加
證據：規則頁截圖、觸發畫面、結算畫面

#### B-011 對帳
步驟：每 5–10 把用「把數 × 押注 − 贏分」對一次餘額；每次免費遊戲 / 寶箱結算都對
預期：全部相符；不符要找到原因

### 穩定性
- [ ] 全程無閃退；若閃退存 logcat 並至少重現 3 次 ｜ 預期：0 次閃退
- [ ] 斷線錯誤碼與重連流程 ｜ 預期：重連後回到原本畫面，錯誤訊息與實際狀況相符

## 探索重點（AI 另外自己找，以下只是提示）
- 進機台的預設押注、額外押注、各種預設勾選
- 規則文字和實際行為不一致的地方
- 點了沒反應、貨幣不足沒說明的功能
- 自動續行（掃蕩券、自動配桌）會不會在玩家沒注意時繼續花錢
- 付費視窗的出現頻率

## 禁止
- 不使用背包道具（加成卡、免費遊戲卡）
