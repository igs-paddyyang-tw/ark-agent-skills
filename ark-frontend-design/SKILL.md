本 Skill 指導產出獨特、生產級品質的前端介面，避免千篇一律的「AI 罐頭風格」。
實作真正可運行的程式碼，對美學細節與創意選擇給予極高關注。

使用者提供前端需求：元件、頁面、應用程式或介面。可能包含用途、受眾或技術限制等背景資訊。

## 設計思維

在寫程式碼之前，先理解情境並確立大膽的美學方向：
- **目的**：這個介面解決什麼問題？誰在使用？
- **調性**：選擇一個極端風格：極簡主義、極繁主義、復古未來、有機自然、奢華精緻、趣味玩具風、雜誌編輯風、粗獷主義、裝飾藝術幾何風、柔和粉彩、工業實用風等。以此為靈感，設計出忠於美學方向的作品。
- **限制**：技術需求（框架、效能、無障礙）。
- **差異化**：什麼讓這個設計令人難忘？使用者會記住的那一件事是什麼？

**關鍵**：選擇清晰的概念方向並精準執行。大膽的極繁主義和精緻的極簡主義都可行——重點是意圖性，而非強度。

然後實作可運行的程式碼（HTML/CSS/JS、React、Vue 等），必須：
- 生產級品質且功能完整
- 視覺上引人注目且令人難忘
- 具有清晰美學觀點的一致性
- 每個細節都經過精心打磨

## 前端美學指南

重點關注：
- **字型**：選擇美觀、獨特、有趣的字型。避免 Arial、Inter 等通用字型；選擇能提升美感的獨特字型。搭配一個有特色的標題字型與精緻的內文字型。
- **色彩與主題**：確立一致的美學風格。使用 CSS 變數確保一致性。主色搭配鮮明強調色，優於膽怯的均勻分佈色盤。
- **動態效果**：使用動畫做效果與微互動。HTML 優先使用純 CSS 方案。React 可用 Motion 函式庫。聚焦高影響力時刻：一個精心編排的頁面載入動畫（搭配 animation-delay 的交錯顯示）比零散的微互動更令人愉悅。善用捲動觸發和令人驚喜的 hover 狀態。
- **空間構圖**：出人意料的排版。不對稱。重疊。對角線流動。打破網格的元素。大量留白或有控制的密度。
- **背景與視覺細節**：營造氛圍與深度，而非預設純色背景。加入符合整體美學的情境效果與紋理。運用漸層網格、雜訊紋理、幾何圖案、多層透明、戲劇性陰影、裝飾邊框、自訂游標、顆粒覆蓋等創意形式。

絕對不要使用千篇一律的 AI 生成美學：過度使用的字型家族（Inter、Roboto、Arial、系統字型）、老套的配色方案（特別是白底紫色漸層）、可預測的排版與元件模式、缺乏情境特色的罐頭設計。

創意詮釋，做出令人意外的選擇，讓設計真正為情境量身打造。每個設計都應該不同。在淺色與深色主題、不同字型、不同美學之間變化。絕對不要在多次產出中收斂到相同的選擇。

**重要**：實作複雜度要匹配美學願景。極繁主義設計需要精心的程式碼、大量動畫與效果。極簡或精緻設計需要克制、精準，以及對間距、字型和微妙細節的仔細關注。優雅來自於對願景的良好執行。

## 設計系統模式（多頁/整個專案時先做這步）

單一 artifact 可直接憑上述美學指南開工；但**多頁面或整個專案**時，先建立設計系統再寫 UI，確保一致性——避免每頁各自收斂成不同風格。

```
AI 預設 UI = 紫色漸層 + 圓角卡片 + 千篇一律
→ 先建設計系統（色彩/字型/間距/元件規範），後續所有 UI code 引用它
```

### 1. 需求分析
確認：產品類型（遊戲 / SaaS / 電商 / 內部工具）、目標受眾、品牌調性、2-3 個參考網站。

### 2. 產出設計系統（`docs/design-system.md`）
色彩表（Primary/Secondary/Background/Surface/Text/Text-muted/Success/Error）、
字型表（H1/H2/Body/Small 的字型/大小/行高）、間距系統（base 4px → 4,8,12,16,24,32,48,64）、
圓角（sm 4 / md 8 / lg 16）、元件規範（Button/Card/Input 的尺寸/狀態）。

### 3. 產出 CSS 變數
```css
:root {
  --color-primary: #XXXXXX; --color-secondary: #XXXXXX;
  --color-bg: #XXXXXX; --color-surface: #XXXXXX; --color-text: #XXXXXX;
  --font-heading: '{font}', sans-serif; --font-body: '{font}', sans-serif;
  --radius-sm: 4px; --radius-md: 8px; --radius-lg: 16px; --space-unit: 4px;
}
```

### 4. 全專案引用
後續所有前端 code 必須引用設計系統變數，**禁止 hardcode 色碼**。

### 產業預設
| 產業 | 主色調 | 風格 |
|------|--------|------|
| 遊戲（捕魚/slot） | 深藍 + 金色 | 暗黑科技、霓虹 |
| SaaS | 藍/紫 + 白 | 乾淨、專業 |
| 電商 | 橘/紅 + 白 | 活潑、促銷感 |
| 內部工具 | 灰 + 藍 | 中性、資訊密度高 |
| 金融 | 深藍 + 綠 | 信任、穩重 |

### 品質檢查
- [ ] 色彩對比度 ≥ 4.5:1（WCAG AA）
- [ ] 正文字型 ≥ 14px
- [ ] 互動元素 ≥ 44px 觸控區域
- [ ] 暗色/亮色模式都定義（如需要）
- [ ] 無 hardcode 色碼（全用 CSS 變數）

> 與 `ark-superpowers` 整合：在 ② Spec 階段先建設計系統存入 `docs/design-system.md`，④ Execute 階段所有 UI code 引用它。
